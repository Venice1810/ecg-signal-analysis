## 📌 Project Overview
This repository contains a modular, quantitative experimental framework for discrete-time electrocardiogram (ECG) signal processing, R-peak detection, conventional time-domain heart rate calculation, and Random Forest regression benchmarking using the PhysioNet MIT-BIH Arrhythmia Database[cite: 2, 7, 11].

---

## 📂 Repository Structure
* **`ecg_hr_pipeline.py`** — Complete automated Python execution script for filtering, peak detection, feature extraction, and ML evaluation[cite: 7, 8, 14].
* **`requirements.txt`** — Required Python library dependencies[cite: 14].
